# Flores Amarillas 💛🌼

Una pequeña página romántica, estática y adaptable a móviles, creada como detalle para Tifany. Incluye una galería de recuerdos, una carta interactiva, música opcional y una animación suave de flores amarillas.

## Ver el proyecto

- Repositorio: https://github.com/JoseGarcia6/Flores-amarilla
- Publicación: habilita GitHub Pages desde la rama `main` y la carpeta raíz (`/(root)`) en **Settings → Pages**.

## Contenido

```text
.
├── index.html
└── src/
    ├── atardecre.jpg
    ├── foto1.jpg
    ├── foto2.jpg
    ├── foto3.jpg
    └── musica.mp3
```

## Funciones

- Diseño cálido con fondo fotográfico y efecto de vidrio.
- Diseño adaptable a pantallas de escritorio y teléfonos.
- Carta que se abre en una ventana interactiva.
- Galería de fotos ampliables.
- Sorpresa interactiva con un mensaje positivo y una lluvia breve de flores, corazones y destellos.
- Control manual para reproducir y pausar la música.
- Flores animadas con una cantidad limitada para reducir trabajo innecesario.
- Respeta la preferencia del sistema por reducir animaciones.
- No requiere frameworks, dependencias, servidores ni claves de API.

## Personalizar

1. Edita los textos de `index.html` para adaptar el mensaje.
2. Sustituye las imágenes conservando los nombres de archivo dentro de `src/`, o actualiza las rutas en el HTML.
3. Sustituye `src/musica.mp3` por la canción que quieras utilizar. La música solo comienza cuando la persona toca el botón, para respetar las políticas de reproducción de los navegadores.
4. Guarda y publica los cambios en GitHub Pages.

## Nota de privacidad

Antes de publicar fotografías personales, asegúrate de contar con el consentimiento de las personas que aparecen en ellas. En un repositorio público, los archivos y el código pueden ser vistos por cualquiera.
